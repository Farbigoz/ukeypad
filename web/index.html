Open-source embedded input platform

Small, fast, configurable USB HID devices.

A low-latency firmware and hardware abstraction project for compact keypads and custom input controllers built around accessible microcontroller boards.

Open configurator View on GitHub

USB-first

Standard HID keyboard output with a deterministic scan path and a configuration channel for setup and diagnostics.

Digital and Hall inputs

Designed to support ordinary mechanical switches, Hall-effect sensors, and mixed devices through compile-time hardware profiles.

Capability-driven

The firmware describes its inputs and features so the browser configurator can build the right interface for each device.

Small-board friendly

Targeting inexpensive USB-capable development boards instead of one fixed controller or proprietary hardware.

Current reference device

The current implementation targets an ESP32-S3 SuperMini with six digital inputs, 2000 Hz scanning, integrator debounce, duplicate-binding support, USB HID, USB CDC configuration, NVS persistence, and a standalone Web Serial configurator.

Planned direction

Future iterations will add compile-time device descriptions, variable button counts, Hall sensor backends with ADC/DMA, mixed digital/Hall devices, dynamic GUI discovery, and one RGB LED per physical button.

input hardware → timer / ADC + DMA → debounce or Hall processing → common KeyEvent pipeline → HID backend ↘ CDC config protocol ↔ Web Serial configurator
