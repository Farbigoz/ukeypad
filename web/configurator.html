USB HID keypad configurator

Standalone Web Serial configurator. Работает в Chrome/Edge на desktop.

Не подключено

Отключи keypad, зажми любую кнопку, подключи USB, затем нажми «Подключить CDC». В config mode HID-нажатия не отправляются.

Этот браузер не поддерживает Web Serial API. Используй Chrome или Edge на desktop.

Дубликаты разрешены: две физические кнопки могут иметь один HID-код.

Тест кнопок

Тест использует тот же timer 2000 Гц и integrator debounce, что и normal mode. События выводятся в лог CDC, HID не отправляет.
