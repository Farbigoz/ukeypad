ukeypad · open-source hardware

A small keypad that does exactly what you need.

Build a compact USB keypad for shortcuts, games, media controls, accessibility, or anything else that benefits from a few dedicated buttons.

Open the configurator Explore the project

Feels like a keyboard

It connects over USB and sends ordinary keyboard keys, so it works with the apps and games you already use.

Set it up your way

Choose what each button does in the browser configurator. Save the setup once and keep using it after reconnecting.

Quick and predictable

The device is built for small, direct actions: press a button, get the key you expect, without a companion app running all the time.

Open and adaptable

The firmware and hardware profile are available in the repository, so the project can grow with your own ideas and boards.

What you can use today

The ready-to-use profile is built for an ESP32-S3 SuperMini and has six digital buttons. You can assign keys such as letters, function keys, arrows, modifiers, and media controls. Settings are saved on the device, and the browser configurator also includes input testing and basic diagnostics.

Getting started

Connect in setup mode

Plug in the keypad via USB; the CDC configuration channel is always available alongside HID.

Choose your keys

Open the configurator in Chrome or Edge, connect to the keypad, and select a key for each button.

Save and use it

Save the configuration, restart without holding a button, and use the keypad like a regular keyboard.

A project in progress

The current release focuses on reliable digital buttons and a simple setup experience. More profiles, lighting, additional boards, and other input types may come later. The repository and README contain the technical details and the current development plan.
